Block 2: Headphone-EEG Recording Outside

{{ endblock }} {{ block content }}

This block takes about 30 minutes. Please find a spot outside with a stable WiFi or mobile hotspot signal to get started.

It has three stages:

  1. Rest & mental arithmetic (~5 min) – a short warm-up task at the start
  2. Walk (~10 min) – walk around freely; an internet connection isn't needed during this part
  3. Rest & mental arithmetic (~5 min) – the same short task again, at the end. Ideally, return to the same spot where you did the first recording.

Before you begin, please set up the EEG recording with your headphones (see the next 2 pages for instructions). You'll be asked to repeat this setup before each rest & mental arithmetic recording.
